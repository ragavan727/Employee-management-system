# Employee-management-system
A full-stack **MERN** web application to manage employees and tasks efficiently within an organization.  
Built with **React, Node.js, Express, MongoDB, Tailwind CSS, HTML, JavaScript, and JSON**.

---

##  Features
- **Login / Authentication**
  - Secure login for users before accessing the system
  - Can validate credentials using backend API
  - Protects employee and task data from unauthorized access
- **Employee Management**
  - Add, update, and delete employee records
  - Real-time UserID validation and ability to update UserID
  - Search employees by name
- **Task Management**
  - Add, update, delete, and assign tasks to employees
  - Change task status: **To Do → In Progress → Testing → Completed**
- **Full CRUD Functionality**
  - Frontend ↔ Backend data synced via RESTful APIs

## 🛠 Technologies Used
- **Frontend:** React.js, HTML, Tailwind CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Data Format:** JSON

## ⚙️ Installation

# Backend
-cd backend
-npm install i express
-npm install i nodemon
-npm install i cors
-npm install i mongoose

# Frontend
-cd frontend
-npm run dev
npm install
npm start
